顾客不满足规则时，订单限购会显示对应的提示。你可以在各类限制首页配置文案和语言，让顾客知道需要怎样调整购物车。

## 修改提示

1. 打开 **数量限制**、**价格限制**、**重量限制** 或 **客户限制** 首页。
2. 在 **顾客提示文案** 点击 **配置提示文案**。
3. 选择 **已添加的语言**，或用 **添加语言** 增加需要的语言。
4. 修改相应的最低、最高、范围或客户资格提示。
5. 点击 **保存**，再用对应语言在前台测试。

各类限制使用各自的模板。数量规则和产品／变体数量限制共用数量限制的提示，不需要给每条数量规则重复填写。

## 保留动态变量

下面是模板示例。复制时请保留双花括号，并使用该类提示支持的变量。不要把数量变量放进金额模板。

### 数量提示

```text
{{itemName}} 最多可购买 {{maxQuantity}} 件，请调整数量后再结账。
```

| 变量 | 含义 |
| --- | --- |
| `{{itemName}}` | 当前产品或适用商品名称 |
| `{{productTitle}}` | 产品名称 |
| `{{minQuantity}}` | 最小数量 |
| `{{maxQuantity}}` | 最大数量 |
| `{{currentQuantity}}` | 当前检查的数量 |
| `{{excessQuantity}}` | 超出数量 |

### 金额提示

```text
适用商品金额至少需达到 {{minAmount}}，当前为 {{currentAmount}}。
```

金额模板支持 `{{itemName}}`、`{{minAmount}}`、`{{maxAmount}}`、`{{currentAmount}}`。

### 重量提示

```text
商品合计重量不能超过 {{maxWeight}}，当前为 {{currentWeight}}。
```

重量模板支持 `{{minWeight}}`、`{{maxWeight}}`、`{{currentWeight}}`。

### 客户资格与登录提示

**客户限制** 中的 **禁止购买提示** 和 **需要客户账户登录提示** 是两项设置。购买资格提示支持 `{{itemName}}`、`{{productTitle}}`，不要添加数量、金额或重量变量。

```text
{{itemName}} 仅向符合资格的客户开放购买。请确认账户资格后再结账。
```

登录提示应明确下一步，例如“请先登录客户账户，再继续购买”。不要承诺登录后一定能购买，客户仍可能不满足标签条件。

### 让提示说清楚怎么修改

使用“哪个商品 + 需要达到的门槛 + 下一步”的顺序。数量上限提示让顾客减少数量；最低金额提示让顾客增加适用商品金额。修改后实际触发一次规则，检查变量是否替换为真实商品和数值。

## 检查语言与实际显示

系统根据店铺前台／结账的语言选择可用模板，未命中时使用回退文案。不同类别的语言匹配细节可能不同，请分别测试你启用的语言和市场。

<Note>后台规则名称只用于管理，不会自动成为顾客提示。将规则名称改为中文，也不会自动把所有顾客提示改成中文。</Note>

如果模板显示不符，先核对类别、语言和保存状态，再检查变量是否仍保留原始拼写。
