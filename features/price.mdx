价格限制检查适用商品的当前金额合计。你可以设置最低金额、最高金额，或同时设置一个金额范围。

## 创建价格规则

1. 从应用首页进入 **价格规则**，创建价格规则。
2. 在 **金额限制** 填写最低金额或最高金额，至少填写一项。
3. 在 **适用商品** 选择所有产品、指定产品或产品系列。
4. 选择 **购物车价格限制**，或 **按客户标签使用不同价格限制**。
5. 设置显示时机，选择 **已启用**，点击 **保存并启用**。
6. 回到 **价格限制**，打开 **开启价格规则**。

## 哪些金额参与计算

| 项目 | 计算方式 |
| --- | --- |
| 适用商品 | 合计购物车中这些商品当前的行金额 |
| 范围外商品 | 不计入这条规则 |
| 划线价 | 不参与计算 |
| 运费、税费 | 不作为商品金额加入门槛 |
| 折扣 | 以校验阶段获得的当前商品行金额为准；请测试实际折扣组合 |

例如，咖啡豆产品系列最低消费 100。咖啡豆当前金额 80，加上杯子 50，仍然不满足这条产品系列规则。

<Note>如果购物车完全没有指定产品或产品系列的商品，这条范围规则不会强制顾客加购。金额达到最低值或正好等于最高值时，满足对应门槛。</Note>

## 不同市场与货币

按店铺基础货币填写门槛。顾客使用其他市场货币结账时，系统按 Shopify 结账汇率换算门槛，并按结账货币精度处理。

例如基础货币门槛是 100，某次结账汇率为 1.2，换算门槛为 120。这个汇率只是计算示例，不是固定汇率。

## 为客户组设置金额

添加一个或多个客户标签，选择带标签或不带标签的客户。多个标签中匹配任意一个，即视为匹配该组。未识别客户标签的访客会落入不匹配标签的一组。

多条命中的价格规则会分别检查，不提供“排在前面自动覆盖后面”的单品数量优先级。

继续操作：[设置最低消费](/scenarios/minimum-order-value) · [批发与零售不同门槛](/scenarios/customer-pricing)。

## 从最低金额改成最高金额或范围

只设最高金额时，最低金额留空，填写最高值。设置范围时同时填写最低和最高金额，最高值不能低于最低值。等于上下限可以通过。修改后用低于下限、正好等于下限、正好等于上限、超过上限四种金额测试。测试流程见[上线清单](/getting-started/launch-checklist)。
