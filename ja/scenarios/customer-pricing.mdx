wholesale タグがある顧客は商品金額 500 以上、それ以外の顧客は 100 以上にします。2 つの金額ルールで対象グループを分けます。

## 設定内容

アプリのホーム → **金額ルール** → 金額ルールの作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルールの種類 | 顧客タグごとに異なる金額制限を使用 |
| 適用商品 | すべての商品 |
| ルール A | wholesale タグあり、最低金額 500 |
| ルール B | wholesale タグなし、最低金額 100 |
| 両ルールの最高金額 | 空欄 |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. テスト用の卸売顧客に `wholesale` タグを追加します。
2. 2 つのルールを作成し、タグを追加して一致条件を選びます。
3. 両方を有効にして保存し、**金額ルールを有効にする** をオンにします。
4. ログイン済みの卸売顧客と一般顧客でそれぞれテストします。

## 設定をテストする

| テスト条件 | このルールの期待結果 |
| --- | --- |
| 卸売顧客、商品金額 499 | 制限 |
| 卸売顧客、商品金額 500 | 許可 |
| 一般顧客、商品金額 100 | 許可 |
| ゲスト、商品金額 99 | タグなしのグループとして制限 |

<Note>一致する金額ルールはすべて確認されます。全顧客向けに最低 500 のルールも残っていると、一般顧客にも 500 の条件が適用されます。</Note>

[金額計算と通貨換算](/ja/features/price)も確認してください。
