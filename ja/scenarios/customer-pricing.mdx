wholesale タグがある顧客は商品金額 500 以上、それ以外の顧客は 100 以上にします。2 つの金額ルールで対象グループを分けます。

## この設定が適する場合

顧客グループごとに最低購入金額を分ける場合に使います。金額制限は購入条件であり、商品の販売価格は変更しません。

## 始める前に

wholesale タグあり・なしの顧客を用意します。基本通貨と、99、100、499、500 の商品金額でテストできることを確認します。

## 設定内容

アプリのホーム → **金額ルール** → 金額ルールの作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルールの種類 | 顧客タグごとに異なる金額制限を使用 |
| 適用商品 | すべての商品 |
| ルール A | wholesale タグあり、最低金額 500 |
| ルール B | wholesale タグなし、最低金額 100 |
| 両ルールの最高金額 | 空欄 |
| 表示タイミング | チェックアウト時のみ |
| ルール名 | 卸売最低金額 500、小売最低金額 100 |
| 両ルールの状態 | 有効 |

## 設定手順

1. Shopify 管理画面のアプリから **订单限制** を開きます。ホームの **价格规则** を開き、**创建价格规则** をクリックします。
2. Shopify の顧客情報に例のタグを追加します。ルールにも同じタグを入力して **添加标签** をクリックし、タグが表示されたことを確認してから条件の向きを選びます。
3. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
4. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
5. 同じ商品範囲でルール A と B を作成します。一方をタグあり、他方をタグなしにし、それぞれの数値を入力します。
6. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**保存并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
7. **价格限制** に戻り、**开启价格规则** をオンにします。保存が完了し、エラーが出ていないことを確認します。
8. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| 卸売顧客、商品金額 499 | 制限 |
| 卸売顧客、商品金額 500 | 許可 |
| 一般顧客、商品金額 100 | 許可 |
| ゲスト、商品金額 99 | タグなしのグループとして制限 |

<Note>一致する金額ルールはすべて確認されます。全顧客向けに最低 500 のルールも残っていると、一般顧客にも 500 の条件が適用されます。</Note>

[金額計算と通貨換算](/ja/features/price)も確認してください。

## 結果が異なる場合

一般顧客にも 500 が要求される場合は、全顧客向けの 500 ルールを確認します。グループ条件はタグあり・なしで分けます。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
