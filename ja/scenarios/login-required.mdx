Order Limit の顧客ルールでは、VIP や卸売タグを使わずにログインだけを要求できます。この例では、指定商品 1 つをすべてのログイン済み顧客が購入できます。

## 始める前に

購入可能な商品と、ストアでログインできる顧客アカウントを用意します。ストアのログイン手順が動作することを確認します。

## 設定内容

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 指定商品はログイン後に購入 |
| 顧客タグ | 追加しない |
| 顧客アカウントのログインを要求 | オン |
| 商品範囲 | 指定商品：テスト商品 |
| 表示タイミング | チェックアウト時のみ |
| 状態 | 有効 |

## 設定手順

1. Shopify のアプリから **订单限制** → **客户限制规则** を開き、**创建规则** をクリックします。
2. ルール名を入力し、タグは空欄にします。**需要客户账户登录** をオンにします。
3. **规则应用于** で **指定产品** を選び、**选择产品** で商品を追加します。商品名の表示を確認してください。
4. **仅结账时** を選び、**保存后的状态** を **已启用** にして **创建并启用** をクリックします。
5. **客户限制** に戻り、**开启客户限制规则** をオンにします。保存成功後にルールを開き直して設定を確認します。

## 設定をテストする

| 条件 | この例の結果 |
| --- | --- |
| ゲストが対象商品をチェックアウト | ログインを要求 |
| VIP なしでログイン済み、対象商品を購入 | このルールでは許可 |
| VIP ありでログイン済み、対象商品を購入 | このルールでは許可 |
| ゲストが対象外の商品だけを購入 | このルールの対象外 |

## 使用上の範囲

商品を隠す、アカウントを作る、タグを付ける機能ではありません。ほかの数量、金額、重量、購入資格ルールは引き続き適用されます。ゲストがカートに追加できても、チェックアウト時のみのルールが無効とは限りません。

VIP のみにするなら[会員限定](/ja/scenarios/members-only)を使います。必要に応じて[トラブルシューティング](/ja/troubleshooting/rules-not-working)を確認し、[公開前テスト](/ja/getting-started/launch-checklist)を行ってください。太字の中国語は実際の画面項目です。
