商品金額が 100 以上になったらチェックアウトを許可する例です。金額ルールを作成し、ストアの基本通貨で条件を入力します。

## 設定内容

アプリのホーム → **金額ルール** → 金額ルールの作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 商品金額は最低 100 |
| 最低金額 | 100 |
| 最高金額 | 空欄 |
| 適用商品 | すべての商品 |
| ルールの種類 | カートの金額制限 |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. 上の条件でルールを作成します。金額はストアの基本通貨で入力します。
2. 状態を **有効** にし、**保存して有効化** をクリックします。
3. **金額制限** に戻り、**金額ルールを有効にする** をオンにします。保存エラーがないか確認します。

## 設定をテストする

| テスト条件 | このルールの期待結果 |
| --- | --- |
| 現在の商品金額が 99 | 制限 |
| 現在の商品金額が 100 | 許可 |
| 現在の商品金額が 120 | 許可 |
| 比較価格の合計 120、現在の商品金額 90 | 制限 |

<Warning>対象商品の金額を確認するルールです。送料や税金を含む最終支払総額とは異なります。実際の割引とマーケットでテストしてください。</Warning>

特定コレクションだけを対象にする場合は適用範囲を変更します。[金額制限](/ja/features/price)を参照してください。
