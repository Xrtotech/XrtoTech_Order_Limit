商品金額が 100 以上になったらチェックアウトを許可する例です。金額ルールを作成し、ストアの基本通貨で条件を入力します。

## この設定が適する場合

商品金額が最低条件に達してから購入を許可する場合に使います。送料無料や割引は設定しません。

## 始める前に

ストアの基本通貨を確認し、商品金額が 99、100、120 になるカートを用意します。最初は割引を使わずテストします。

## 設定内容

アプリのホーム → **金額ルール** → 金額ルールの作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 商品金額は最低 100 |
| 最低金額 | 100 |
| 最高金額 | 空欄 |
| 適用商品 | すべての商品 |
| ルールの種類 | カートの金額制限 |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. Shopify 管理画面のアプリから **订单限购** を開きます。ホームの **价格规则** を開き、**创建价格规则** をクリックします。
2. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
3. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
4. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**保存并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
5. **价格限制** に戻り、**开启价格规则** をオンにします。保存が完了し、エラーが出ていないことを確認します。
6. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| 現在の商品金額が 99 | 制限 |
| 現在の商品金額が 100 | 許可 |
| 現在の商品金額が 120 | 許可 |
| 比較価格の合計 120、現在の商品金額 90 | 制限 |

<Warning>対象商品の金額を確認するルールです。送料や税金を含む最終支払総額とは異なります。実際の割引とマーケットでテストしてください。</Warning>

特定コレクションだけを対象にする場合は適用範囲を変更します。[金額制限](/ja/features/price)を参照してください。

## 結果が異なる場合

商品 90 と送料 10 では条件の 100 に達しません。商品金額、割引、市場の通貨換算、ほかの金額ルールを確認します。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
