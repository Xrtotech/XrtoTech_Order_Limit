限定カップを販売し、1 注文で最大 2 点まで購入できるようにします。個別計算の数量ルールでは、同じ商品の全バリエーションを合計します。

## 設定内容

アプリのホーム → **すべての数量ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 限定カップは最大 2 点 |
| 種類 | カートの数量制限 |
| 最小数量 | 空欄 |
| 最大数量 | 2 |
| 計算方法 | 対象商品をそれぞれ個別に制限 |
| 適用範囲 | 指定商品：限定カップ |
| 表示タイミング | カート操作時とチェックアウト時 |

## 設定手順

1. 上の設定内容で数量ルールを作成し、実際の商品またはコレクションを選びます。
2. 状態を **有効** にして、**保存して有効化** をクリックします。
3. **数量制限** に戻り、**数量ルールを有効にする** をオンにします。**カートとチェックアウトの検証** も有効になっているか確認します。

## 設定をテストする

| テスト条件 | このルールの期待結果 |
| --- | --- |
| カップ 2 点 | 許可 |
| カップ 3 点 | 制限 |
| 同じ商品の赤 1 点 + 青 2 点 | 合計 3 点のため制限 |
| カップ 2 点 + 対象外のコースター 3 点 | このルールでは許可 |

<Note>このルールはカートごとの制限です。同じ顧客が複数回注文しても、2 点の枠を共有する設定にはなりません。</Note>

再購入を管理する場合は[サンプルの再購入制限](/ja/scenarios/repeat-purchase)を参照してください。
