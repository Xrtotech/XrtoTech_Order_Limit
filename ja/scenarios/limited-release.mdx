限定カップを販売し、1 注文で最大 2 点まで購入できるようにします。個別計算の数量ルールでは、同じ商品の全バリエーションを合計します。

## この設定が適する場合

限定販売や小売キャンペーンで、商品ごとの単回購入数を制限する場合に使います。

## 始める前に

購入可能で在庫のあるカップを用意します。赤と青は同じ商品のバリエーションにします。対象外のコースターも用意してください。

## 設定内容

アプリのホーム → **すべての数量ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 限定カップは最大 2 点 |
| 種類 | カートの数量制限 |
| 最小数量 | 空欄 |
| 最大数量 | 2 |
| 計算方法 | 対象商品をそれぞれ個別に制限 |
| 適用範囲 | 指定商品：限定カップ |
| 表示タイミング | カート操作時とチェックアウト時 |

## 設定手順

1. Shopify 管理画面のアプリから **订单限购** を開きます。ホームの **所有数量规则** を開き、**创建规则** をクリックします。
2. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
3. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
4. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**创建并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
5. **数量限制** に戻り、**数量规则** をオンにします。**数量规则开关** が有効か確認し、**数量规则** を開き、状態が **已开启** になることを確認します。
6. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| カップ 2 点 | 許可 |
| カップ 3 点 | 制限 |
| 同じ商品の赤 1 点 + 青 2 点 | 合計 3 点のため制限 |
| カップ 2 点 + 対象外のコースター 3 点 | このルールでは許可 |

<Note>このルールはカートごとの制限です。同じ顧客が複数回注文しても、2 点の枠を共有する設定にはなりません。</Note>

再購入を管理する場合は[サンプルの再購入制限](/ja/scenarios/repeat-purchase)を参照してください。

## 結果が異なる場合

色ごとに 2 点買うと、同じ商品の合計が上限を超えます。異なる商品で枠を共有する場合は合計数量ルールを使います。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
