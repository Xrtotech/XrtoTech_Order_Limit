同じ顧客が同じサンプルを再購入できないようにする例です。購入記録がない顧客の初回数量は累計ルールだけでは制限されないため、1 回につき 1 点の数量ルールも作成します。

## 設定内容

アプリのホームの **すべての数量ルール** と **顧客累計ルール** を使います。

| 項目 | 設定例 |
| --- | --- |
| ルール A の種類 | カートの数量制限 |
| ルール A の最大数量 | 1 |
| ルール A の計算方法 | 対象商品をそれぞれ個別に制限 |
| ルール B の種類 | 顧客の累計購入制限 |
| ルール B の過去購入数量の条件 | 1 |
| 両ルールの適用範囲 | 指定商品：同じサンプル |
| 両ルールの状態 | 有効 |

## 設定手順

1. [単一商品のガイド](/ja/scenarios/limited-release)に従いルール A を作成し、最大数量を `1` にします。
2. **顧客累計ルール** でルール B を作成します。過去購入数量の条件を `1` にし、同じサンプルを選びます。
3. 両方を有効にして保存し、数量ルールとカート・チェックアウトの検証を有効にします。
4. サンプルの記録がないテスト顧客でログインして初回注文を作成します。購入記録の更新後、2 回目の購入をテストします。

## 設定をテストする

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済み、記録なし、初回 1 点 | 許可 |
| ログイン済み、記録なし、初回 2 点 | ルール A が制限 |
| 1 点の記録があり、さらに 1 点購入 | ルール B が制限 |
| ゲストがサンプルを入れてチェックアウト | ログインが必要 |

<Warning>日次、月次、メールアドレス単位のリセット型制限ではありません。初回購入、記録の更新遅延、返金の扱いを確認してから運用してください。</Warning>

必ず[累計購入の集計範囲と注意点](/ja/features/purchase-history)を確認してください。
