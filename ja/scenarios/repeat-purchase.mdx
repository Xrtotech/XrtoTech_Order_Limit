同じ顧客が同じサンプルを再購入できないようにする例です。購入記録がない顧客の初回数量は累計ルールだけでは制限されないため、1 回につき 1 点の数量ルールも作成します。

## この設定が適する場合

同じ顧客アカウントのサンプル再購入を管理する場合に使います。累計ルールだけでは初回の数量を制限できないため、2 つのルールを使います。

## 始める前に

非サブスクリプションのサンプルと、購入記録のないログイン可能なテスト顧客を用意します。初回テストでは注文を作成し、状態と時刻を記録します。

## 設定内容

アプリのホームの **すべての数量ルール** と **顧客累計ルール** を使います。

| 項目 | 設定例 |
| --- | --- |
| ルール A の種類 | カートの数量制限 |
| ルール A の最大数量 | 1 |
| ルール A の計算方法 | 対象商品をそれぞれ個別に制限 |
| ルール B の種類 | 顧客の累計購入制限 |
| ルール B の過去購入数量の条件 | 1 |
| 両ルールの適用範囲 | 指定商品：同じサンプル |
| 両ルールの状態 | 有効 |
| ルール名 | サンプル単回最大 1、サンプル累計閾値 1 |
| 両ルールの表示タイミング | カート操作時とチェックアウト時 |

## 設定手順

1. 先に[単品の設定手順](/ja/scenarios/limited-release)でルール A を作成します。同じサンプル、個別計算、最大 `1` にします。以下のルール B だけでは代用できません。
2. Shopify 管理画面のアプリから **订单限购** を開きます。ホームの **客户累计规则** を開き、**创建规则** をクリックします。
3. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
4. **规则应用于** で **指定产品** を選び、**选择产品** でルール A と同じサンプルを追加します。名前が一致するか確認します。累計ルールではコレクションは使えません。
5. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**创建并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
6. **数量限制** に戻り、**开启数量规则** をオンにします。**购物车与结账校验** が有効か確認し、必要なら **启用校验** をクリックします。
7. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。
8. 購入記録のないテスト顧客でログインし、初回の注文を作成します。記録更新後に同じアカウントとサンプルで再度チェックアウトします。返金やキャンセルでは枠は自動復元されません。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済み、記録なし、初回 1 点 | 許可 |
| ログイン済み、記録なし、初回 2 点 | ルール A が制限 |
| 1 点の記録があり、さらに 1 点購入 | ルール B が制限 |
| ゲストがサンプルを入れてチェックアウト | ログインが必要 |

<Warning>日次、月次、メールアドレス単位のリセット型制限ではありません。初回購入、記録の更新遅延、返金の扱いを確認してから運用してください。</Warning>

必ず[累計購入の集計範囲と注意点](/ja/features/purchase-history)を確認してください。

## 結果が異なる場合

初回に 2 点買える場合はルール A を確認します。再購入できる場合は、同じ顧客・商品か、非サブスクリプションか、記録が更新されたか確認します。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
