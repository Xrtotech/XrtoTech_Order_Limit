reseller タグがある顧客には、小売向けセールコレクションを購入させたくない場合の例です。タグに一致した顧客を顧客制限でブロックします。

## この設定が適する場合

特定タグの顧客をセール対象商品の購入から除外する場合に使います。同じ人の別アカウントを識別する保証はありません。

## 始める前に

小売セール用コレクションと、reseller タグあり・なしのテスト顧客を用意します。

## 設定内容

アプリのホーム → **顧客制限ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 再販業者は小売セール商品を購入不可 |
| 顧客タグ | reseller |
| タグ制限の方式 | これらのタグがある顧客は購入できない |
| 顧客アカウントへのログインを必須にする | チェックする |
| 対象商品 | コレクション：小売セール |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. Shopify 管理画面のアプリから **订单限购** を開きます。ホームの **客户限制规则** を開き、**创建规则** をクリックします。
2. Shopify の顧客情報に例のタグを追加します。ルールにも同じタグを入力して **添加标签** をクリックし、タグが表示されたことを確認してから条件の向きを選びます。
3. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
4. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
5. **标签限制方式** の向きを表と照合し、**需要客户账户登录** をオンにします。
6. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**创建并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
7. **客户限制** に戻り、**开启客户限制规则** をオンにします。保存が完了し、エラーが出ていないことを確認します。
8. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済みの reseller 顧客がセール商品を購入 | 制限 |
| reseller タグのないログイン済み顧客が購入 | このルールでは許可 |
| ゲストがセール商品を購入 | 先にログインが必要 |
| reseller 顧客が対象外の商品だけ購入 | このルールの対象外 |

<Note>ログイン必須の条件は、このコレクションを買う一般顧客にも適用されます。タグは識別された顧客に基づくため、同じ人による別アカウントの利用を検出する機能ではありません。</Note>

逆のタグ条件を使う例は[会員限定商品](/ja/scenarios/members-only)を参照してください。

## 結果が異なる場合

タグなしの顧客にもログインを求めるのはこの設定の意図どおりです。タグありの顧客が買える場合は、顧客、タグ、コレクション所属を確認します。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
