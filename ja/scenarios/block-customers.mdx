reseller タグがある顧客には、小売向けセールコレクションを購入させたくない場合の例です。タグに一致した顧客を顧客制限でブロックします。

## 設定内容

アプリのホーム → **顧客制限ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | 再販業者は小売セール商品を購入不可 |
| 顧客タグ | reseller |
| タグ制限の方式 | これらのタグがある顧客は購入できない |
| 顧客アカウントへのログインを必須にする | チェックする |
| 対象商品 | コレクション：小売セール |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. 対象顧客の情報に `reseller` タグがあることを確認します。
2. ルールを作成し、タグ入力後に **タグを追加** をクリックします。
3. 有効にして保存し、**顧客制限ルールを有効にする** をオンにします。

## 設定をテストする

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済みの reseller 顧客がセール商品を購入 | 制限 |
| reseller タグのないログイン済み顧客が購入 | このルールでは許可 |
| ゲストがセール商品を購入 | 先にログインが必要 |
| reseller 顧客が対象外の商品だけ購入 | このルールの対象外 |

<Note>ログイン必須の条件は、このコレクションを買う一般顧客にも適用されます。タグは識別された顧客に基づくため、同じ人による別アカウントの利用を検出する機能ではありません。</Note>

逆のタグ条件を使う例は[会員限定商品](/ja/scenarios/members-only)を参照してください。
