VIP タグがある顧客だけに会員専用コレクションの購入を許可します。顧客制限を作成し、アカウントへのログインも必須にします。

## 設定内容

アプリのホーム → **顧客制限ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | VIP 限定コレクション |
| 顧客タグ | VIP。入力後にタグを追加 |
| タグ制限の方式 | これらのタグがない顧客は購入できない |
| 顧客アカウントへのログインを必須にする | チェックする |
| 対象商品 | コレクション：会員限定 |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. 購入資格のある Shopify 顧客に `VIP` タグを追加します。
2. ルールを作成し、**これらのタグがない顧客は購入できない** を選びます。
3. **有効** にして保存します。**顧客制限** に戻り、**顧客制限ルールを有効にする** をオンにします。

## 設定をテストする

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済み VIP が限定商品を購入 | 購入資格の条件を満たす |
| VIP タグのないログイン済み顧客が購入 | 制限 |
| ゲストが限定商品を購入 | ログインが必要 |
| 一般顧客が対象外の商品だけ購入 | このルールの対象外 |

<Warning>購入資格を制限する機能です。商品ページ、価格、コレクションを自動で非表示にはしません。</Warning>

必要に応じて [VIP の数量枠](/ja/scenarios/vip-quantity)も設定できます。
