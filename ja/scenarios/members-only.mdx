VIP タグがある顧客だけに会員専用コレクションの購入を許可します。顧客制限を作成し、アカウントへのログインも必須にします。

## この設定が適する場合

会員商品の購入資格を制限する場合に使います。会員の数量枠を増やす場合は顧客タグ別数量ルールを使います。

## 始める前に

会員用コレクションと、VIP タグあり・なしの顧客を用意し、ストアでログインできることを確認します。

## 設定内容

アプリのホーム → **顧客制限ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | VIP 限定コレクション |
| 顧客タグ | VIP。入力後にタグを追加 |
| タグ制限の方式 | これらのタグがない顧客は購入できない |
| 顧客アカウントへのログインを必須にする | チェックする |
| 対象商品 | コレクション：会員限定 |
| 表示タイミング | チェックアウト時のみ |

## 設定手順

1. Shopify 管理画面のアプリから **订单限制** を開きます。ホームの **客户限制规则** を開き、**创建规则** をクリックします。
2. Shopify の顧客情報に例のタグを追加します。ルールにも同じタグを入力して **添加标签** をクリックし、タグが表示されたことを確認してから条件の向きを選びます。
3. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
4. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
5. **标签限制方式** の向きを表と照合し、**需要客户账户登录** をオンにします。
6. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**创建并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
7. **客户限制** に戻り、**开启客户限制规则** をオンにします。保存が完了し、エラーが出ていないことを確認します。
8. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済み VIP が限定商品を購入 | 購入資格の条件を満たす |
| VIP タグのないログイン済み顧客が購入 | 制限 |
| ゲストが限定商品を購入 | ログインが必要 |
| 一般顧客が対象外の商品だけ購入 | このルールの対象外 |

<Warning>購入資格を制限する機能です。商品ページ、価格、コレクションを自動で非表示にはしません。</Warning>

必要に応じて [VIP の数量枠](/ja/scenarios/vip-quantity)も設定できます。

## 結果が異なる場合

VIP が制限される場合はタグ条件の向きを確認します。タグなしの顧客を制限する設定にし、ルールと顧客の両方に VIP を追加します。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
