セールのコレクションに商品 A、B、C があります。組み合わせは自由にしつつ、カート内の対象商品を合計 3 点までに制限します。

## この設定が適する場合

複数のサンプルやセール商品で数量枠を共有する場合に使います。セット商品や割引を自動作成する機能ではありません。

## 始める前に

Shopify で異なる商品 A、B、C を含むセール用コレクションと、対象外の商品を用意します。

## 設定内容

アプリのホーム → **すべての数量ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| ルール名 | セール商品は合計 3 点まで |
| 種類 | カートの数量制限 |
| 最大数量 | 3 |
| 計算方法 | カート内の対象商品の合計数量を制限 |
| 適用範囲 | コレクション：セール商品 |
| 表示タイミング | カート操作時とチェックアウト時 |

## 設定手順

1. Shopify 管理画面のアプリから **订单限制** を開きます。ホームの **所有数量规则** を開き、**创建规则** をクリックします。
2. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
3. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
4. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**创建并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
5. **数量限制** に戻り、**数量规则** をオンにします。**数量规则开关** が有効か確認し、**数量规则** を開き、状態が **已开启** になることを確認します。
6. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| A を 1 点 + B を 2 点 | 合計 3 点なので許可 |
| A を 2 点 + B を 2 点 | 合計 4 点なので制限 |
| A を 3 点 + 対象外の商品 5 点 | このルールでは許可 |
| 対象コレクションの商品なし | このルールの対象外 |

<Tip>後からコレクションに追加した商品も対象になります。固定の商品一覧にしたい場合は **指定商品** を使ってください。</Tip>

計算方法の違いは[数量制限](/ja/features/quantity)で確認できます。

## 結果が異なる場合

A を 2 点、B を 2 点で通過する場合は、合計計算を選んだか、両商品が対象コレクションに入っているか確認します。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
