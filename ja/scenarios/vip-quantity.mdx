新商品について、VIP は最大 4 点、その他の顧客は最大 2 点にします。互いに重ならない 2 つの顧客タグ別ルールを作成します。

## この設定が適する場合

会員と一般顧客の単回購入枠を変える場合に使います。VIP タグで条件を分けますが、会員制度は作成しません。

## 始める前に

新商品と、VIP タグあり・なしのテスト顧客を用意します。ルールへのタグ入力だけでは顧客にタグは付与されません。

## 設定内容

アプリのホーム → **顧客タグ別数量ルール** → ルール作成を開きます。

| 項目 | 設定例 |
| --- | --- |
| 両ルールの種類 | 顧客タグごとに異なる数量を使用 |
| 両ルールの適用範囲 | 指定商品：同じ新商品 |
| 両ルールの計算方法 | 対象商品をそれぞれ個別に制限 |
| ルール A のタグ条件 | VIP タグがある顧客 |
| ルール A の最大数量 | 4 |
| ルール B のタグ条件 | VIP タグがない顧客 |
| ルール B の最大数量 | 2 |
| ルール名 | VIP 最大 4 点、非 VIP 最大 2 点 |
| 両ルールの最小値 | 空欄 |
| 表示タイミング | カート操作時とチェックアウト時 |
| 状態 | 有効 |

## 設定手順

1. Shopify 管理画面のアプリから **订单限购** を開きます。ホームの **客户标签数量规则** を開き、**创建规则** をクリックします。
2. Shopify の顧客情報に例のタグを追加します。ルールにも同じタグを入力して **添加标签** をクリックし、タグが表示されたことを確認してから条件の向きを選びます。
3. 上の表に従ってルール名と数値を入力します。ルール名は管理用で、顧客には表示しません。
4. **规则应用于** で表の適用範囲を選びます。指定商品やコレクションでは **选择产品** または **选择产品系列** をクリックし、選んだ名前が表示されたことを確認します。
5. 同じ商品範囲でルール A と B を作成します。一方をタグあり、他方をタグなしにし、それぞれの数値を入力します。
6. 表示タイミングを表に合わせます。**保存后的状态** で **已启用** を選び、**创建并启用** をクリックします。既存ルールの編集時は **保存并启用** を使います。
7. **数量限制** に戻り、**开启数量规则** をオンにします。**购物车与结账校验** が有効か確認し、必要なら **启用校验** をクリックします。
8. ルールを開き直し、数値、範囲、顧客条件、有効状態が保存されていることを確認します。その後、下の表でストアをテストします。
9. **所有数量规则** で専用ルールを同じ商品に一致する汎用の個別ルールより上に移動し、汎用枠が先に使われないようにします。

## 設定をテストする

表はこの設定だけの判定です。同じ商品範囲でチェックアウトまで確認してください。ほかの有効ルールで制限される場合もあります。

| テスト条件 | このルールの期待結果 |
| --- | --- |
| ログイン済みの VIP が 4 点購入 | 許可 |
| ログイン済みの VIP が 5 点購入 | 制限 |
| VIP タグのないログイン済み顧客が 3 点購入 | 制限 |
| ゲストが 3 点購入 | VIP タグが認識されないため制限 |

<Note>タグのテストでは対象顧客のアカウントでログインしてください。VIP の上限を使うには、ストアが顧客を識別できる必要があります。</Note>

重複するルールは[優先順位](/ja/settings/rule-priority)を確認してください。

## 結果が異なる場合

VIP でも 2 点までになる場合は、ログイン中の顧客、追加済みタグ、順序、バリエーション上限、コレクション合計上限を確認します。

[トラブルシューティング](/ja/troubleshooting/rules-not-working)で原因を確認し、公開前に[テスト一覧](/ja/getting-started/launch-checklist)を完了してください。
