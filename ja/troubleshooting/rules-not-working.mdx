Order Limit の動作が想定と異なる場合は、商品、顧客、カートを 1 つずつ固定してください。1 回に 1 つの設定だけを変えると、原因を切り分けやすくなります。

<Steps>
<Step title="有効化を確認する">
ルールが **下書き** になっていないか確認します。保存後に開き直し、設定値を確認してください。金額、重量、顧客ルールには各概要画面のスイッチも必要です。

数量制限では **数量ルールを有効にする** または **商品の数量制限を有効にする** が設定方法と一致しているか確認し、**カートとチェックアウトの検証** も有効にします。
</Step>
<Step title="商品範囲と計算方法を確認する">
カート内の実際の商品が選択されているか確認します。コレクションは現在の所属で判定します。数量の個別計算と合計計算を取り違えていないか確認してください。
</Step>
<Step title="顧客の識別を確認する">
タグのテストでは対象アカウントでログインします。Shopify 顧客情報のタグ、ルールでの **タグを追加**、タグあり・なしの方向を確認します。
</Step>
<Step title="正しい段階でテストする">
チェックアウト時のみのルールはカート操作時に確認されません。数量の最低条件もチェックアウトで確認します。カートに追加できたことだけでは無効とは判断できません。
</Step>
<Step title="ほかのルールを切り分ける">
一覧の順序、バリエーション制限、合計・累計ルールを確認します。無関係なルールを一時的に下書きにし、テスト後に 1 つずつ戻してください。
</Step>
</Steps>

## 症状から探す

| 症状 | 最初に確認すること |
| --- | --- |
| VIP の上限が低い | ログイン、タグ、先行する汎用ルール、バリエーション・合計上限 |
| 最低数量未満でも追加できる | チェックアウトに進んで最低条件を確認 |
| 金額は足りているのに制限される | 対象商品の現在の行金額、対象外商品、割引、通貨換算 |
| 重量が実際より軽い | 各バリエーションの有効な重量と単位 |
| 初回の大量購入が累計条件を通過する | 別の単回数量ルールを設定 |
| 返金後も購入数量が残る | 返金による自動減算はない |
| コレクション外の商品が制限される | 全商品ルールや、カートに残る対象商品 |
| 特定テーマでメッセージが出ない | 実際のチェックアウト検証後、カートの表示を確認 |

## 保存できない場合

画面のエラーを確認してください。コレクション、タグ、メッセージが多すぎると保存できない場合があります。不要な設定を減らして再試行し、スイッチの見た目だけで判断しないでください。

問い合わせる場合はルール名、商品、ログイン状態、タグ、数量・金額・重量、再現手順、実際のメッセージを用意します。共有前に顧客の連絡先などの個人情報を除いてください。

[優先順位](/ja/settings/rule-priority)も参照してください。
