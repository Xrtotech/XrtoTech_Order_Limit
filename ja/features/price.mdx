金額制限は対象商品の現在の金額を合計して判定します。最低金額、最高金額、または両方を使った範囲を設定できます。

## 金額ルールを作成する

1. アプリのホームから **金額ルール** を開き、ルールを作成します。
2. 最低金額または最高金額を入力します。少なくとも一方が必要です。
3. すべての商品、指定商品、コレクションから適用範囲を選びます。
4. **カートの金額制限** または **顧客タグごとに異なる金額制限を使用** を選びます。
5. 表示タイミングと **有効** を選び、**保存して有効化** をクリックします。
6. **金額制限** に戻り、**金額ルールを有効にする** をオンにします。

## 計算に含まれる金額

| 項目 | 扱い |
| --- | --- |
| 対象商品 | カート内の現在の行金額を合計 |
| 対象外の商品 | 含めない |
| 比較価格 | 含めない |
| 送料・税金 | 商品金額として追加しない |
| 割引 | 検証時に取得できる現在の行金額を使用。実際の割引の組み合わせをテストする |

コーヒーのコレクションに最低 100 を設定した場合、コーヒー 80 と対象外のマグカップ 50 では条件を満たしません。

<Note>指定商品やコレクションの商品がカートにない場合、その範囲の購入を強制しません。最低金額や最高金額と同額なら、その条件を満たします。</Note>

## マーケットと通貨

金額はストアの基本通貨で入力します。別通貨でのチェックアウトでは、Shopify のチェックアウト為替レートと対象通貨の精度で条件を換算します。

基本通貨の条件が 100、為替レートが 1.2 の場合は 120 になります。このレートは説明用の例で、固定値ではありません。

## 顧客グループ

タグを追加して、タグあり・タグなしの顧客を選びます。複数タグはどれか 1 つに一致すれば一致と判定します。タグが認識されないゲストはタグなし側になります。

一致する金額ルールはすべて確認されます。数量の個別ルールのような「先頭のルールで上書き」は行いません。

設定例：[最低購入金額](/ja/scenarios/minimum-order-value)、[卸売と小売で条件を変える](/ja/scenarios/customer-pricing)。
