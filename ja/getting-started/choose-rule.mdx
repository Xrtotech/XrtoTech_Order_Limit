Order Limit の入口は目的ごとに分かれています。最初に<strong>「誰が、どの商品を、どの条件で購入するか」</strong>を決めます。すべての設定を先に覚える必要はありません。

## 目的から手順を選ぶ

| 目的 | 使う設定 | ガイド |
| --- | --- | --- |
| 同じ商品の色違いを合計 2 点まで | 商品ごとの個別数量 | [限定販売](/ja/scenarios/limited-release) |
| 複数商品を合わせて 3 点まで | 合計数量 | [組み合わせ購入](/ja/scenarios/mix-and-match) |
| 商品ごとに最低 6 点 | 個別の最低数量 | [卸売の最低数量](/ja/scenarios/wholesale-minimum) |
| 青は最大 1 点、商品全体は最大 3 点 | 商品とバリエーションの制限 | [商品別設定](/ja/getting-started/product-variant-limits) |
| VIP は 4 点、その他は 2 点 | 顧客タグ別数量 | [顧客別の枠](/ja/scenarios/vip-quantity) |
| 商品金額を最低 100 にする | 金額ルール | [最低金額](/ja/scenarios/minimum-order-value) |
| 卸売は最低 500、その他は 100 | 顧客タグ別金額 | [グループ別金額](/ja/scenarios/customer-pricing) |
| 商品重量を 20 kg までにする | 重量ルール | [重量上限](/ja/scenarios/shipping-weight) |
| VIP だけがコレクションを買える | タグの許可条件 | [会員限定](/ja/scenarios/members-only) |
| タグに関係なくログインを要求する | ログインのみの顧客ルール | [ログイン必須](/ja/scenarios/login-required) |
| 特定タグの顧客を購入対象から除外 | タグの拒否条件 | [特定顧客の制限](/ja/scenarios/block-customers) |
| 同じアカウントのサンプル再購入を制限 | 単回上限と累計ルール | [再購入制限](/ja/scenarios/repeat-purchase) |

## 作成前に決める 4 項目

1. **商品範囲**：全商品、固定の商品一覧、今後も更新するコレクションのどれですか。
2. **顧客条件**：全員、タグあり、タグなし、ログイン必須のどれですか。
3. **計算方法**：商品ごとに個別で計算しますか。対象商品すべてで枠を共有しますか。
4. **タイミング**：カートとチェックアウト、またはチェックアウトのみですか。最低数量はチェックアウトで確認します。

「コレクション合計で 3 点まで」では合計計算が必要です。個別計算では各商品に 3 点の枠ができます。

## 似ている条件を区別する

- 注文ごとの最大 2 点と、記録された累計購入枠は別です。
- 最低 6 点なら 7 点も買えます。6 の倍数指定ではありません。
- 金額制限は価格変更、割引、送料無料を設定しません。
- 購入資格の制限は商品ページや価格を非表示にしません。
- 重量制限は荷物分割、送料計算、配送業者の選択を行いません。

まず[最初のルール](/ja/quickstart)を作り、[公開前テスト](/ja/getting-started/launch-checklist)で確認します。実際の画面項目は[中国語の対応表](/ja/getting-started/how-it-works#アプリ画面の項目を確認する)で探せます。
