Order Limit は、カート内の対象商品と顧客条件を確認します。ルールを作る前に、どの商品を、どの顧客に、どのタイミングで制限するか決めてください。

## 最初に知っておく用語

| 用語 | 商品の例 |
| --- | --- |
| 商品 | 1 種類の商品 |
| バリエーション | 同じ商品の赤、青、サイズ |
| コレクション | 商品やコースターを含むセール用グループ |
| 個別計算 | 商品ごとに枠を持ち、同じ商品のバリエーションは合計 |
| 合計計算 | 一致するすべての商品で閾値を共有 |
| 顧客タグ | Shopify の顧客情報にある VIP などのラベル |
| 累計購入 | 同じ顧客の記録済み商品購入数。今回のカートとは別 |

## 有効化の 3 つの段階

| 段階 | 確認すること |
| --- | --- |
| 個別のルール | **下書き** ではなく **有効** になっている |
| 機能のスイッチ | 該当する種類のルールがオンになっている |
| 検証 | 数量の検証が有効で、ほかの種類でも保存・有効化エラーが出ていない |

商品・バリエーションの制限と数量ルールは別の設定です。商品一覧で数値を編集する場合は商品の数量制限を、ルール編集画面で作成する場合は数量ルールを有効にします。

## 商品の適用範囲

- **すべての商品**：カート内の全商品を確認します。
- **指定商品**：選択した商品だけを確認します。
- **コレクション**：現在の所属情報で判定します。後から追加された商品も対象になります。

累計購入ルールは、すべての商品または指定商品に対応します。コレクションは指定できません。

## 対象外の商品を買う場合

指定商品やコレクションの最低条件は、その対象商品がカートにある場合に適用されます。コーヒーの最低金額を設定しても、マグカップだけを買う顧客にコーヒーの追加は要求しません。

## 表示タイミング

**カート操作時とチェックアウト時** または **チェックアウト時のみ** を選びます。数量の最低条件はチェックアウトで確認されるため、顧客は 1 点ずつ追加できます。実際のテーマでカートとチェックアウトの表示を確認してください。

<Warning>数量、金額、重量、購入資格のルールが重なる場合、すべての条件を満たす必要があります。購入可能な組み合わせが残っているか確認してください。</Warning>

## アプリ画面の項目を確認する

このガイドでは画面項目を日本語で説明しています。現在のソースにあるアプリ画面は中国語です。以下の対応表を使って項目を探してください。日本語のアプリ画面が提供されていることを示すものではありません。

| ガイド内の表記 | 中国語の画面項目 |
| --- | --- |
| Order Limit | 订单限制 |
| 数量制限 / すべての数量ルール | 数量限制 / 所有数量规则 |
| 顧客タグ別数量ルール / 顧客累計ルール | 客户标签数量规则 / 客户累计规则 |
| 金額ルール / 重量ルール / 顧客制限ルール | 价格规则 / 重量规则 / 客户限制规则 |
| カートの数量制限 | 购物车数量限制 |
| 対象商品をそれぞれ個別に制限 | 分别限制每个适用商品 |
| カート内の対象商品の合計数量を制限 | 限制购物车内适用商品的加购数量合计 |
| すべての商品 / 指定商品 / コレクション | 所有产品 / 指定产品 / 产品系列 |
| 顧客タグ / タグを追加 | 客户标签 / 添加标签 |
| 有効 / 下書き / 作成して有効化 / 保存して有効化 | 已启用 / 草稿 / 创建并启用 / 保存并启用 |
| 数量ルールを有効にする | **数量规则** → **已开启** |
| メッセージ設定 / 保存 | 配置提示文案 / 保存 |
| 顧客アカウントへのログインを必須にする | 需要客户账户登录 |

複数ルールを使う前に、[ルールの優先順位](/ja/settings/rule-priority)を確認してください。

## ルールが適用されるまで

```mermaid
flowchart LR
    A[ルール作成] --> B[有効で保存] --> C[機能をオン] --> D[検証を確認] --> E[許可と制限をテスト]
```

種類に迷ったら[Order Limit について](/ja/index)を確認します。一時停止、復元、テスト記録は[公開前テスト](/ja/getting-started/launch-checklist)を使います。
