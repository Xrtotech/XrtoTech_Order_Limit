Order Limit は、条件を満たさない顧客に制限メッセージを表示します。各種類の概要画面で編集し、カートをどう変更すればよいか伝えてください。

## メッセージを編集する

1. **数量制限**、**金額制限**、**重量制限**、**顧客制限** の概要を開きます。
2. 顧客向けメッセージの **メッセージ設定** をクリックします。
3. 追加済みの言語を選ぶか、**言語を追加** を使います。
4. 最低、最高、範囲、購入資格の該当メッセージを編集します。
5. **保存** し、そのストア・チェックアウト言語でテストします。

種類ごとに独立したテンプレートを使います。商品・バリエーションの数量設定と数量ルールは共通の数量テンプレートを使うため、ルールごとの入力は不要です。

## 変数をそのまま保持する

その種類で対応する変数だけを使用してください。例をコピーするときは、二重の波括弧と正確なつづりを保持します。

### 数量メッセージ

```text
{{itemName}} は最大 {{maxQuantity}} 点まで購入できます。数量を変更してからお進みください。
```

| 変数 | 意味 |
| --- | --- |
| `{{itemName}}` | 商品または対象アイテムの名前 |
| `{{productTitle}}` | 商品名 |
| `{{minQuantity}}` | 最小数量 |
| `{{maxQuantity}}` | 最大数量 |
| `{{currentQuantity}}` | 判定対象の数量 |
| `{{excessQuantity}}` | 超過数量 |

### 金額メッセージ

```text
対象商品の合計金額は {{minAmount}} 以上が必要です。現在は {{currentAmount}} です。
```

金額テンプレートは `{{itemName}}`、`{{minAmount}}`、`{{maxAmount}}`、`{{currentAmount}}` に対応します。

### 重量メッセージ

```text
対象商品の合計重量は {{maxWeight}} 以内にしてください。現在は {{currentWeight}} です。
```

重量テンプレートは `{{minWeight}}`、`{{maxWeight}}`、`{{currentWeight}}` に対応します。

### 購入資格とログインのメッセージ

**客户限制** の **禁止购买提示** と **需要客户账户登录提示** は別項目です。購入資格の文面は `{{itemName}}` と `{{productTitle}}` に対応します。数量、金額、重量の変数を追加しないでください。

```text
{{itemName}} は購入資格のある顧客のみ購入できます。アカウントの資格を確認してからお進みください。
```

ログインの文面では、ログインしてから再試行するよう案内します。タグ条件もあるため、ログインだけで必ず購入できるとは書かないでください。

### 次の操作を伝える

対象商品、閾値、次の操作の順に書きます。上限なら数量を減らし、最低金額なら対象商品の金額を増やすよう案内します。保存後に実際に制限を発生させ、変数が正しい商品名と数値に置き換わるか確認します。

## 言語ごとの表示を確認する

ストア・チェックアウトの言語と登録済みテンプレートに応じてメッセージを選び、必要に応じて代替文を使います。言語の一致方法は種類によって異なるため、利用する言語とマーケットごとにテストしてください。

<Note>ルール名は管理用です。名前を変更しても顧客メッセージは翻訳されません。ヘルプの表示言語を変えても、ストアのメッセージ設定は変わりません。</Note>

想定した文が出ない場合は、種類、言語、保存状態、変数のつづりを確認してください。
