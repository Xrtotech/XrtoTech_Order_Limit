VIP customers can buy up to 4 units of a new product, while everyone else can buy 2. Two complementary customer-tag rules keep the customer groups separate.

## When to use this

Use this to give members and other customers different allowances. The VIP tag selects the allowance; it does not create a membership program.

## Before you begin

Prepare one new product, a test customer tagged VIP and a customer without that tag. Adding a tag to a rule does not assign it to customer profiles.

## Settings

Open the app home page → **Customer tag quantity rules** → create a rule.

| Setting | Example value |
| --- | --- |
| Rule type for both rules | Use different quantities by customer tag |
| Scope for both rules | Specific products: the same new product |
| Calculation for both rules | Limit each applicable item individually |
| Rule A: tag condition | Customers with any of these tags: VIP |
| Rule A: maximum | 4 |
| Rule B: tag condition | Customers without these tags: VIP |
| Rule B: maximum | 2 |
| Rule names | VIP maximum 4; non-VIP maximum 2 |
| Minimum for both | Blank |
| Timing | Cart interactions and checkout |
| Status | Active |

## Steps

1. Open **Apps** → **订单限购** in Shopify. From the app home page, open **客户标签数量规则** and click **创建规则**.
2. Add the example tag to the customer profile in Shopify. In the rule, enter the same tag, click **添加标签**, and check that it appears before choosing the tag condition.
3. Enter the rule name and thresholds from the settings table. The name is for admin use only.
4. Under **规则应用于**, select the scope in the table. For selected products or collections, click **选择产品** or **选择产品系列** and confirm the selected names appear.
5. Create both rule A and rule B with the same product scope. Match tagged customers in one and untagged customers in the other; set each threshold separately.
6. Set the timing from the table. Under **保存后的状态**, select **已启用** and click **创建并启用**. When editing an existing rule, click **保存并启用**.
7. Return to **数量限制** and turn on **开启数量规则**. Confirm **购物车与结账校验** is enabled, using **启用校验** if necessary.
8. Reopen the rule to confirm its thresholds, scope, customer conditions and active state were saved. Run the storefront tests below.
9. In **所有数量规则**, move dedicated rules above any general individual rule for the same product so the general allowance does not match first.

## Test your configuration

Each result describes this recipe only. Keep the product scope consistent and verify checkout; other active rules may still block the cart.

| Test | Expected result for this scenario |
| --- | --- |
| Signed-in VIP buys 4 | Allowed |
| Signed-in VIP buys 5 | Blocked |
| Signed-in customer without VIP buys 3 | Blocked |
| Guest buys 3 | Blocked as the VIP tag is not identified |

<Note>Sign in with the appropriate customer account when testing tags. The store must identify the customer to use the VIP allowance.</Note>

See [rule priority](/en/settings/rule-priority) for overlapping rules.

## If results differ

If a VIP still gets only 2 units, check the signed-in account, the added tag, list order, variant caps and combined collection caps.

Use [troubleshooting](/en/troubleshooting/rules-not-working) to investigate. Complete the [launch checklist](/en/getting-started/launch-checklist) before rolling out.
