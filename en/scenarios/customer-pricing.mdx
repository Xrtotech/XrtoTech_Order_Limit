Customers tagged wholesale must reach 500 in merchandise value. Other customers must reach 100. Two price rules apply different thresholds to these separate groups.

## When to use this

Use this for customer groups with different order minimums. Price limits set purchase thresholds; they do not change product prices.

## Before you begin

Prepare customers with and without the wholesale tag. Confirm the store currency and carts of 99, 100, 499 and 500.

## Settings

Open the app home page → **Price rules** → create a price rule.

| Setting | Example value |
| --- | --- |
| Rule type | Use different price limits by customer tag |
| Applicable products | All products |
| Rule A | Tag wholesale, customers with the tag, minimum 500 |
| Rule B | Tag wholesale, customers without the tag, minimum 100 |
| Maximum amount for both | Leave blank |
| Timing | Checkout only |
| Rule names | Wholesale minimum 500; retail minimum 100 |
| Status for both | Active |

## Steps

1. Open **Apps** → **订单限制** in Shopify. From the app home page, open **价格规则** and click **创建价格规则**.
2. Add the example tag to the customer profile in Shopify. In the rule, enter the same tag, click **添加标签**, and check that it appears before choosing the tag condition.
3. Enter the rule name and thresholds from the settings table. The name is for admin use only.
4. Under **规则应用于**, select the scope in the table. For selected products or collections, click **选择产品** or **选择产品系列** and confirm the selected names appear.
5. Create both rule A and rule B with the same product scope. Match tagged customers in one and untagged customers in the other; set each threshold separately.
6. Set the timing from the table. Under **保存后的状态**, select **已启用** and click **保存并启用**. When editing an existing rule, click **保存并启用**.
7. Return to **价格限制** and turn on **开启价格规则**. Wait for saving to complete and check for errors.
8. Reopen the rule to confirm its thresholds, scope, customer conditions and active state were saved. Run the storefront tests below.

## Test your configuration

Each result describes this recipe only. Keep the product scope consistent and verify checkout; other active rules may still block the cart.

| Test | Expected result for this scenario |
| --- | --- |
| Wholesale customer: 499 | Blocked |
| Wholesale customer: 500 | Allowed |
| Regular customer: 100 | Allowed |
| Guest: 99 | Blocked under the non-matching group |

<Note>Every matching price rule is checked. Remove or revise an additional all-customer minimum of 500; otherwise regular customers must satisfy it too.</Note>

Read [price calculations and currency conversion](/en/features/price).

## If results differ

If retail customers also need 500, check for a general 500 minimum. One group rule must match the tag and the other must match its absence.
