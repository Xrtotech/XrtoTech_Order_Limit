You are launching a limited-edition product and want each order to contain at most 2 units. An individual quantity rule totals all variants of that product.

## When to use this

Use this for limited launches and retail promotions that cap each product in one purchase.

## Before you begin

Prepare a purchasable product with enough stock. variant A and variant B must be variants of the same product. Use an unselected coaster to test scope.

## Settings

Open the app home page → **All quantity rules** → create a rule.

| Setting | Example value |
| --- | --- |
| Rule name | Limited product: maximum 2 |
| Rule type | Cart quantity limit |
| Minimum quantity | Leave blank |
| Maximum quantity | 2 |
| Calculation | Limit each applicable item individually |
| Scope | Specific products: limited product |
| Timing | Cart interactions and checkout |

## Steps

1. Open **Apps** → **订单限制** in Shopify. From the app home page, open **所有数量规则** and click **创建规则**.
2. Enter the rule name and thresholds from the settings table. The name is for admin use only.
3. Under **规则应用于**, select the scope in the table. For selected products or collections, click **选择产品** or **选择产品系列** and confirm the selected names appear.
4. Set the timing from the table. Under **保存后的状态**, select **已启用** and click **创建并启用**. When editing an existing rule, click **保存并启用**.
5. Return to **数量限制** and turn on **数量规则**. Confirm **数量规则开关** is enabled, open the **数量规则** switch until it shows **已开启**.
6. Reopen the rule to confirm its thresholds, scope, customer conditions and active state were saved. Run the storefront tests below.

## Test your configuration

Each result describes this recipe only. Keep the product scope consistent and verify checkout; other active rules may still block the cart.

| Test | Expected result for this scenario |
| --- | --- |
| 2 product units | Allowed |
| 3 product units | Blocked |
| 1 variant A product + 2 variant B product units, variants of the same product | Blocked: product total is 3 |
| 2 product units + 3 coasters outside the scope | Allowed by this rule |

<Note>This rule checks each cart. It does not share a 2-unit allowance across multiple orders by the same customer.</Note>

For repeat purchases, see [sample purchase limits](/en/scenarios/repeat-purchase).

## If results differ

Two units of each color exceed this cap because variants share the product allowance. To share an allowance across different products, use a combined rule.

Use [troubleshooting](/en/troubleshooting/rules-not-working) to investigate. Complete the [launch checklist](/en/getting-started/launch-checklist) before rolling out.
