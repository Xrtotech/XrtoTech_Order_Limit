如果订单限购没有按预期拦截，先固定一个产品、一个客户和一个购物车测试。每次只调整一个设置，避免多条规则同时改变结果。

<Steps>
<Step title="确认规则真的已启用">
  打开规则，确认状态不是 **草稿**。保存后重新进入，检查参数是否保留。价格、重量和客户规则还需要各自首页的开关开启。

  数量限制还要确认 **数量规则** 或 **开启产品数量限制** 与你的配置入口一致，并且 **数量规则** 显示 **已开启**。
</Step>
<Step title="核对商品范围和计算方式">
  确认选中了购物车中的实际产品。产品系列按当前归属匹配。数量规则检查 **分别限制每个适用商品** 还是 **合计**，不要把两种效果混用。
</Step>
<Step title="核对客户身份">
  测试标签规则时，用对应账户登录。确认 Shopify 客户资料中的标签与规则一致，且已经点击 **添加标签**。检查“带标签”和“不带标签”方向。
</Step>
<Step title="进入正确的测试阶段">
  **仅结账时** 的规则不会在购物车互动时检查。数量最低门槛也在结账时检查。不要只根据加购成功判断规则失效。
</Step>
<Step title="排除其他规则影响">
  查看 **所有规则** 中的顺序，检查变体限制、合计规则与累计规则。把无关规则暂设为草稿后重新测试，再逐条恢复。
</Step>
</Steps>

## 按现象定位

| 现象 | 优先检查 |
| --- | --- |
| VIP 额度仍然很低 | 是否登录、标签是否匹配、通用单品规则是否在前、是否还有变体或合计上限 |
| 不足起订量也能加购 | 数量最低门槛在结账阶段检查 |
| 金额看似够了仍被拦截 | 适用商品当前金额、范围外商品、折扣、结账市场换算 |
| 重量远低于实际 | 每个变体是否有有效重量与正确单位 |
| 累计门槛未限制首次大额购买 | 首次购买需要额外单次数量规则 |
| 退款后仍受累计限制 | 当前没有自动回退购买数量的处理 |
| 指定产品系列外商品也被拦截 | 是否有全店规则，或购物车中仍含产品系列内商品 |
| 只有某个主题看不到提示 | 用实际结账验证拦截，再检查主题购物车展示方式 |

## 保存失败时

读取页面中的错误信息。产品系列、标签或提示文案过多时，配置可能无法保存。先减少不必要的范围和文案，再重试，不要只看开关外观判断是否生效。

如果仍需协助，准备规则名称、适用产品、客户是否登录、标签、购物车数量／金额／重量、操作步骤和实际提示。共享资料前移除客户联系方式和订单个人信息。

继续阅读：[规则优先级](/settings/rule-priority)。
