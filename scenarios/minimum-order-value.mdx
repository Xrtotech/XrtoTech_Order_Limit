你希望顾客购物车中的商品金额达到 100 后才能结账。使用价格限制，以店铺基础货币填写门槛。

## 适用场景

适合希望订单达到最低商品金额再接受结账的店铺。这里设置购买条件，不会自动设置包邮或折扣。

## 开始前

先确认店铺基础货币。准备能组合出商品金额 99、100、120 的测试购物车。初次测试先不叠加折扣。

## 配置参数

入口：应用首页 → **价格规则** → 创建价格规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 全店商品最低消费 100 |
| 最低金额 | 100 |
| 最高金额 | 留空 |
| 适用商品 | 所有产品 |
| 规则类型 | 购物车价格限制 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限制**。从应用首页进入 **价格规则**，点击 **创建价格规则**。
2. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
3. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
4. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **保存并启用**。编辑已有规则时点击 **保存并启用**。
5. 回到 **价格限制**，打开 **开启价格规则**。等待保存完成，确认页面没有错误信息。
6. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 适用商品当前金额合计 99 | 拦截 |
| 适用商品当前金额合计 100 | 通过 |
| 适用商品当前金额合计 120 | 通过 |
| 划线价合计 120，但当前商品金额合计 90 | 拦截 |

<Warning>这里计算的是适用商品当前金额合计，不是含运费和税费的订单最终应付总额。折扣和不同市场请使用实际结账结果测试。</Warning>

只对指定产品系列设金额门槛？将 **适用商品** 改为 **产品系列**。详见[价格限制](/features/price)。

## 结果不符时

商品 90 加运费 10 不能凑成这条规则的 100。先看商品当前金额，再检查折扣、市场换算和其他价格规则。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
