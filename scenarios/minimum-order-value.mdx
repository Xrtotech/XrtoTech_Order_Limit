你希望顾客购物车中的商品金额达到 100 后才能结账。使用价格限制，以店铺基础货币填写门槛。

## 配置参数

入口：应用首页 → **价格规则** → 创建价格规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 全店商品最低消费 100 |
| 最低金额 | 100 |
| 最高金额 | 留空 |
| 适用商品 | 所有产品 |
| 规则类型 | 购物车价格限制 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 按上表创建价格规则。金额按店铺基础货币填写。
2. 将状态设为 **已启用**，点击 **保存并启用**。
3. 回到 **价格限制**，打开 **开启价格规则**，确认没有保存错误。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 适用商品当前金额合计 99 | 拦截 |
| 适用商品当前金额合计 100 | 通过 |
| 适用商品当前金额合计 120 | 通过 |
| 划线价合计 120，但当前商品金额合计 90 | 拦截 |

<Warning>这里计算的是适用商品当前金额合计，不是含运费和税费的订单最终应付总额。折扣和不同市场请使用实际结账结果测试。</Warning>

只对指定系列设金额门槛？将 **适用商品** 改为 **产品系列**。详见[价格限制](/features/price)。
