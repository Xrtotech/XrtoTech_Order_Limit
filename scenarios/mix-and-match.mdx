你准备一个促销产品系列，其中有 A、B、C 三款商品。希望顾客自由组合，但购物车中该产品系列合计最多购买 3 件。

## 适用场景

适合多款试用装、促销商品共享购买额度。这里允许自由搭配，不会自动生成套餐或折扣。

## 开始前

在 Shopify 中准备促销产品系列，并把 A、B、C 三个不同产品加入该产品系列。另备一个产品系列外商品。

## 配置参数

入口：应用首页 → **所有数量规则** → 创建规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 促销产品系列合计最多 3 件 |
| 规则类型 | 购物车数量限制 |
| 最大购买数量 | 3 |
| 数量计算方式 | 限制购物车内适用商品的加购数量合计 |
| 适用对象 | 产品系列，选择促销产品系列 |
| 显示时机 | 购物车互动时和结账时 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限购**。从应用首页进入 **所有数量规则**，点击 **创建规则**。
2. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
3. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
4. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **创建并启用**。编辑已有规则时点击 **保存并启用**。
5. 回到 **数量限制**，打开 **开启数量规则**。确认 **购物车与结账校验** 为 **已启用**；尚未启用时点击 **启用校验**。
6. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| A 1 件 + B 2 件 | 通过，合计 3 件 |
| A 2 件 + B 2 件 | 拦截，合计 4 件 |
| A 3 件 + 产品系列外商品 5 件 | 通过本条规则 |
| 购物车没有促销产品系列商品 | 不受本条规则限制 |

<Tip>以后加入该产品系列的产品会按当前产品系列归属参与匹配。如果只想固定一批商品，改用 **指定产品**。</Tip>

比较两种计算方式：[数量限制](/features/quantity)。

## 结果不符时

A 买 2 件、B 买 2 件还可通过时，先检查是否误选了分别计算，再确认两个产品都在所选产品系列内。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
