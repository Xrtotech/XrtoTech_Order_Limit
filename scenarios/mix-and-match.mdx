你准备一个促销系列，其中有 A、B、C 三款商品。希望顾客自由组合，但购物车中该系列合计最多购买 3 件。

## 配置参数

入口：应用首页 → **所有数量规则** → 创建规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 促销系列合计最多 3 件 |
| 规则类型 | 购物车数量限制 |
| 最大购买数量 | 3 |
| 数量计算方式 | 限制购物车内适用商品的加购数量合计 |
| 适用对象 | 产品系列，选择促销系列 |
| 显示时机 | 购物车互动时和结账时 |

## 操作步骤

1. 按上表填写规则，选择实际的产品或产品系列。
2. 将 **规则状态** 设为 **已启用**，点击 **保存并启用**。
3. 回到 **数量限制**，打开 **开启数量规则**，并确认 **购物车与结账校验** 已启用。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| A 1 件 + B 2 件 | 通过，合计 3 件 |
| A 2 件 + B 2 件 | 拦截，合计 4 件 |
| A 3 件 + 系列外商品 5 件 | 通过本条规则 |
| 购物车没有促销系列商品 | 不受本条规则限制 |

<Tip>以后加入该系列的产品会按当前系列归属参与匹配。如果只想固定一批商品，改用 **指定产品**。</Tip>
