你希望 VIP 客户每次最多购买 4 件新品，其他客户最多购买 2 件。使用两条互斥的客户标签数量规则，避免通用规则先命中。

## 配置参数

入口：应用首页 → **客户标签数量规则** → 创建规则。

| 设置项 | 示例值 |
| --- | --- |
| 两条规则的类型 | 按客户标签使用不同数量 |
| 两条规则的适用对象 | 指定产品，选择同一款新品 |
| 两条规则的计算方式 | 分别限制每个适用商品 |
| 规则 A 的标签匹配 | 带有这些标签的客户，添加 VIP |
| 规则 A 的最大数量 | 4 |
| 规则 B 的标签匹配 | 不带这些标签的客户，添加 VIP |
| 规则 B 的最大数量 | 2 |

## 操作步骤

1. 先在 Shopify 客户资料中给测试会员添加 `VIP` 标签。
2. 按上表创建并启用两条规则。客户标签输入后，点击 **添加标签**。
3. 回到 **数量限制** 开启数量规则并启用校验。
4. 进入 **所有数量规则**，检查是否还有覆盖该商品的通用单品规则。如有，将专属规则上移到通用规则之前。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且带 VIP 标签，购买 4 件 | 通过 |
| 已登录且带 VIP 标签，购买 5 件 | 拦截 |
| 已登录且不带 VIP 标签，购买 3 件 | 拦截 |
| 访客购买 3 件 | 按未识别到 VIP 标签处理，拦截 |

<Note>客户需要让店铺识别其客户身份，才能使用标签额度。测试 VIP 规则时，请先登录对应客户账户。</Note>

多条规则如何组合：[规则优先级](/settings/rule-priority)。
