你希望 VIP 客户每次最多购买 4 件新品，其他客户最多购买 2 件。使用两条互斥的客户标签数量规则，避免通用规则先命中。

## 适用场景

适合会员与普通客户享有不同单次购买额度。VIP 标签决定额度，不自动提供会员注册或会员等级体系。

## 开始前

准备同一款新品，以及一个有 VIP 标签、一个没有 VIP 标签的测试客户。标签在 Shopify 客户资料中维护，不是输入到规则后就自动分配给客户。

## 配置参数

入口：应用首页 → **客户标签数量规则** → 创建规则。

| 设置项 | 示例值 |
| --- | --- |
| 两条规则的类型 | 按客户标签使用不同数量 |
| 两条规则的适用对象 | 指定产品，选择同一款新品 |
| 两条规则的计算方式 | 分别限制每个适用商品 |
| 规则 A 的标签匹配 | 带有这些标签的客户，添加 VIP |
| 规则 A 的最大数量 | 4 |
| 规则 B 的标签匹配 | 不带这些标签的客户，添加 VIP |
| 规则 B 的最大数量 | 2 |
| 两条规则名称 | VIP 每单最多 4 件；非 VIP 每单最多 2 件 |
| 两条规则最小数量 | 留空 |
| 显示时机 | 购物车互动时和结账时 |
| 保存后的状态 | 已启用 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限制**。从应用首页进入 **客户标签数量规则**，点击 **创建规则**。
2. 先到 Shopify 客户资料添加表中的标签。回到规则输入相同标签，点击 **添加标签**，确认已显示为标签项，再选择表中的匹配方向。
3. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
4. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
5. 分别创建规则 A 和规则 B。两条规则使用相同商品范围，标签条件一条选带有，一条选不带；不要复制后忘记修改方向和数值。
6. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **创建并启用**。编辑已有规则时点击 **保存并启用**。
7. 回到 **数量限制**，打开 **数量规则**。确认 **数量规则** 显示 **已开启**；如果显示为关闭，直接打开 **数量规则** 开关，直到状态显示 **已开启**。
8. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。
9. 在 **所有数量规则** 中检查同一产品的通用单品规则。把专属规则移到通用规则之前，避免先命中通用额度。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且带 VIP 标签，购买 4 件 | 通过 |
| 已登录且带 VIP 标签，购买 5 件 | 拦截 |
| 已登录且不带 VIP 标签，购买 3 件 | 拦截 |
| 访客购买 3 件 | 按未识别到 VIP 标签处理，拦截 |

<Note>客户需要让店铺识别其客户身份，才能使用标签额度。测试 VIP 规则时，请先登录对应客户账户。</Note>

多条规则如何组合：[规则优先级](/settings/rule-priority)。

## 结果不符时

VIP 仍只能买 2 件时，核对登录账户、VIP 标签是否已添加到规则、列表顺序，以及产品变体或产品系列合计是否另有限制。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
