你不希望带有 reseller 标签的客户购买零售促销系列。使用客户限制，拦截匹配到该标签的客户。

## 配置参数

入口：应用首页 → **客户限制规则** → 创建客户限制规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 经销商不可购买零售促销 |
| 客户标签 | reseller |
| 标签限制方式 | 有这些标签的客户不能购买 |
| 需要客户账户登录 | 勾选 |
| 符合条件的物品 | 产品系列，选择零售促销系列 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 确认目标客户资料中已添加 `reseller` 标签。
2. 按上表建立规则，输入标签后点击 **添加标签**。
3. 选择 **已启用** 并保存，然后打开 **开启客户限制规则**。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且带 reseller 标签，购买促销商品 | 拦截 |
| 已登录且没有 reseller 标签，购买促销商品 | 通过本条规则 |
| 未登录，购买促销商品 | 要求先登录 |
| 带 reseller 标签，但购物车只有系列外商品 | 不受本条规则限制 |

<Note>勾选登录要求意味着普通客户购买该系列时也要登录。客户标签限制依赖可识别的客户身份，不能作为跨账户身份去重工具。</Note>

标签方向相反的配置：[会员专享系列](/scenarios/members-only)。
