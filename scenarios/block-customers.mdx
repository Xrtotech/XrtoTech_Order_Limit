你不希望带有 reseller 标签的客户购买零售促销产品系列。使用客户限制，拦截匹配到该标签的客户。

## 适用场景

适合让指定标签客户不能购买某一促销范围。它按客户账户判断，不是防止同一个人换账户购买的保证。

## 开始前

准备零售促销产品系列、带 reseller 标签的客户和不带该标签的客户。仅使用演示客户资料。

## 配置参数

入口：应用首页 → **客户限制规则** → 创建客户限制规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 经销商不可购买零售促销 |
| 客户标签 | reseller |
| 标签限制方式 | 有这些标签的客户不能购买 |
| 需要客户账户登录 | 勾选 |
| 适用对象 | 产品系列，选择零售促销产品系列 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限购**。从应用首页进入 **客户限制规则**，点击 **创建规则**。
2. 先到 Shopify 客户资料添加表中的标签。回到规则输入相同标签，点击 **添加标签**，确认已显示为标签项，再选择表中的匹配方向。
3. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
4. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
5. 在 **标签限制方式** 核对表中的方向，并勾选 **需要客户账户登录**。
6. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **创建并启用**。编辑已有规则时点击 **保存并启用**。
7. 回到 **客户限制**，打开 **开启客户限制规则**。等待保存完成，确认页面没有错误信息。
8. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且带 reseller 标签，购买促销商品 | 拦截 |
| 已登录且没有 reseller 标签，购买促销商品 | 通过本条规则 |
| 未登录，购买促销商品 | 要求先登录 |
| 带 reseller 标签，但购物车只有产品系列外商品 | 不受本条规则限制 |

<Note>勾选登录要求意味着普通客户购买该产品系列时也要登录。客户标签限制依赖可识别的客户身份，不能作为跨账户身份去重工具。</Note>

标签方向相反的配置：[会员专享产品系列](/scenarios/members-only)。

## 结果不符时

无标签客户也被要求登录是本例的预期效果。若标签客户能购买，核对登录身份、标签是否添加成功、商品是否属于所选产品系列。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
