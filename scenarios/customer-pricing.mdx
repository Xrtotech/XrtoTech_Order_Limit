你给批发客户添加了 wholesale 标签，希望批发订单商品金额至少 500，其他客户至少 100。使用两条价格规则分别匹配两组客户。

## 适用场景

适合按客户组区分最低起订金额。本例中的“价格限制”是购买金额门槛，不是修改商品售价。

## 开始前

准备带 wholesale 标签的客户和不带该标签的客户。确认基础货币，并准备商品金额 99、100、499、500 的购物车。

## 配置参数

入口：应用首页 → **价格规则** → 创建价格规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则类型 | 按客户标签使用不同价格限制 |
| 适用商品 | 所有产品 |
| 规则 A | 标签 wholesale，带有这些标签的客户，最低金额 500 |
| 规则 B | 标签 wholesale，不带这些标签的客户，最低金额 100 |
| 两条规则的最高金额 | 留空 |
| 显示时机 | 仅结账时 |
| 两条规则名称 | 批发最低金额 500；零售最低金额 100 |
| 两条规则状态 | 已启用 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限制**。从应用首页进入 **价格规则**，点击 **创建价格规则**。
2. 先到 Shopify 客户资料添加表中的标签。回到规则输入相同标签，点击 **添加标签**，确认已显示为标签项，再选择表中的匹配方向。
3. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
4. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
5. 分别创建规则 A 和规则 B。两条规则使用相同商品范围，标签条件一条选带有，一条选不带；不要复制后忘记修改方向和数值。
6. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **保存并启用**。编辑已有规则时点击 **保存并启用**。
7. 回到 **价格限制**，打开 **开启价格规则**。等待保存完成，确认页面没有错误信息。
8. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 批发客户，商品金额 499 | 拦截 |
| 批发客户，商品金额 500 | 通过 |
| 普通客户，商品金额 100 | 通过 |
| 访客，商品金额 99 | 拦截，按未匹配标签的一组检查 |

<Note>多条命中的价格规则都会检查。请不要再保留一条面向所有客户、最低金额 500 的通用规则，否则普通客户也需要满足它。</Note>

了解计算金额和市场换算：[价格限制](/features/price)。

## 结果不符时

普通客户也被要求达到 500 时，检查是否残留了一条适用所有客户的 500 规则。两条组别规则要一条带标签、一条不带标签。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
