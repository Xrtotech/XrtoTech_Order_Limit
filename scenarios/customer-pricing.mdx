你给批发客户添加了 wholesale 标签，希望批发订单商品金额至少 500，其他客户至少 100。使用两条价格规则分别匹配两组客户。

## 配置参数

入口：应用首页 → **价格规则** → 创建价格规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则类型 | 按客户标签使用不同价格限制 |
| 适用商品 | 所有产品 |
| 规则 A | 标签 wholesale，带有这些标签的客户，最低金额 500 |
| 规则 B | 标签 wholesale，不带这些标签的客户，最低金额 100 |
| 两条规则的最高金额 | 留空 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 确认测试批发客户已经添加 `wholesale` 标签。
2. 创建上表中的两条规则，分别添加标签并选择相应匹配方式。
3. 两条规则都选择 **已启用** 并保存，然后打开 **开启价格规则**。
4. 用登录的批发客户和普通客户分别测试。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 批发客户，商品金额 499 | 拦截 |
| 批发客户，商品金额 500 | 通过 |
| 普通客户，商品金额 100 | 通过 |
| 访客，商品金额 99 | 拦截，按未匹配标签的一组检查 |

<Note>多条命中的价格规则都会检查。请不要再保留一条面向所有客户、最低金额 500 的通用规则，否则普通客户也需要满足它。</Note>

了解计算金额和市场换算：[价格限制](/features/price)。
