你希望同一客户领取一种样品后不能再次购买。客户累计规则对首次购买不设数量门槛，因此要同时建立单次最多 1 件的数量规则。

## 适用场景

适合管理同一客户账户的样品复购。你需要两条规则配合；只建累计规则不能限制首次购买数量。

## 开始前

准备一种非订阅样品和一个能登录的全新测试客户。这个客户应没有该样品已记录的购买数量。首次测试需要真实创建一笔测试订单，记录订单状态与测试时间。

## 配置参数

入口：应用首页 → **所有数量规则** 和 **客户累计规则**。

| 设置项 | 示例值 |
| --- | --- |
| 规则 A：规则类型 | 购物车数量限制 |
| 规则 A：最大购买数量 | 1 |
| 规则 A：数量计算方式 | 分别限制每个适用商品 |
| 规则 B：规则类型 | 客户累计购买限制 |
| 规则 B：历史已购达到多少件后限制再次购买 | 1 |
| 两条规则适用对象 | 指定产品，选择同一种样品 |
| 两条规则状态 | 已启用 |
| 规则名称 | 样品单次最多 1 件；样品累计门槛 1 件 |
| 两条规则显示时机 | 购物车互动时和结账时 |

## 操作步骤

1. 先按[单品限购步骤](/scenarios/limited-release)创建规则 A：同一种样品、分别计算、最大数量 `1`。下面的累计规则是规则 B，不能替代规则 A。
2. 在 Shopify 后台打开 **应用** → **订单限购**。从应用首页进入 **客户累计规则**，点击 **创建规则**。
3. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
4. 在 **规则应用于** 选择 **指定产品**，点击 **选择产品**，选中与规则 A 相同的样品。确认名称一致。累计规则不支持产品系列。
5. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **创建并启用**。编辑已有规则时点击 **保存并启用**。
6. 回到 **数量限制**，打开 **开启数量规则**。确认 **购物车与结账校验** 为 **已启用**；尚未启用时点击 **启用校验**。
7. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。
8. 以无记录的测试客户登录并完成首次测试下单。待记录更新后，使用同一账户、同一种样品再次结账。退款或取消订单不会自动恢复额度。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且无购买记录，首次买 1 件 | 通过 |
| 已登录且无购买记录，首次买 2 件 | 被规则 A 拦截 |
| 已记录该样品 1 件，再买 1 件 | 被规则 B 拦截 |
| 访客购买样品并进入结账 | 要求登录 |

<Warning>历史限制不是按天、按月或按邮箱重置的限购。首次购买、记录更新延迟和退款处理都有边界，请先阅读下方说明，再用于正式促销。</Warning>

必读：[客户累计购买限制的统计边界](/features/purchase-history)。

## 结果不符时

首次可买 2 件时，先检查单次上限规则 A。第二次未被限制时，检查是否同一客户、同一产品、非订阅商品，以及购买记录是否已经更新。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
