如果你只想让顾客登录后再购买某些商品，不需要划分 VIP 或批发客户，可以用订单限购的客户规则仅开启登录要求。本例对一个指定产品生效，所有已登录客户都可以购买。

## 开始前

准备一个前台可购买的测试产品，以及一个可在前台登录的客户账户。先确认店铺的登录流程能正常完成。

## 配置参数

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 指定产品登录后购买 |
| 客户标签 | 不添加 |
| 需要客户账户登录 | 勾选 |
| 规则应用于 | 指定产品，选择测试产品 |
| 显示时机 | 仅结账时 |
| 保存后的状态 | 已启用 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限购** → **客户限制规则**，点击 **创建规则**。
2. 填写规则名称，保持客户标签为空。勾选 **需要客户账户登录**。
3. 在 **规则应用于** 选择 **指定产品**，点击 **选择产品** 并选中测试产品，确认名称已出现。
4. 选择 **仅结账时**，将 **保存后的状态** 设为 **已启用**，点击 **创建并启用**。
5. 回到 **客户限制**，打开 **开启客户限制规则**，等待保存成功。重新打开规则确认设置保留。

## 测试你的设置

| 测试条件 | 本例预期结果 |
| --- | --- |
| 访客购买指定产品并进入结账 | 要求登录 |
| 已登录、没有 VIP 标签，购买指定产品 | 通过本条规则 |
| 已登录、有 VIP 标签，购买指定产品 | 通过本条规则 |
| 访客只买范围外商品 | 不受本条规则限制 |

## 使用边界

这条规则不会隐藏商品或创建客户账户，也不会自动给客户打标签。其他数量、金额、重量或资格规则仍会检查。访客在购物车中可以加购，不代表仅结账时的规则失效。

如果你要“仅 VIP 能买”，请改用[会员专享](/scenarios/members-only)。结果不符时检查[规则排查](/troubleshooting/rules-not-working)，上线前完成[测试清单](/getting-started/launch-checklist)。
