你发布一款限量水杯，希望每个订单最多买 2 件。使用数量规则按产品分别计算，同一产品的不同颜色会合并计数。

## 配置参数

入口：应用首页 → **所有数量规则** → 创建规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 限量水杯每单最多 2 件 |
| 规则类型 | 购物车数量限制 |
| 最小购买数量 | 留空 |
| 最大购买数量 | 2 |
| 数量计算方式 | 分别限制每个适用商品 |
| 适用对象 | 指定产品，选择限量水杯 |
| 显示时机 | 购物车互动时和结账时 |

## 操作步骤

1. 按上表填写规则，选择实际的产品或产品系列。
2. 将 **规则状态** 设为 **已启用**，点击 **保存并启用**。
3. 回到 **数量限制**，打开 **开启数量规则**，并确认 **购物车与结账校验** 已启用。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 水杯 2 件 | 通过 |
| 水杯 3 件 | 拦截 |
| 红色水杯 1 件 + 蓝色水杯 2 件，同属一个产品 | 拦截，产品合计 3 件 |
| 水杯 2 件 + 未选中的杯垫 3 件 | 通过本条规则 |

<Note>本场景限制每次购物车的数量。顾客分多次下单时，不会自动共享这个 2 件上限。</Note>
