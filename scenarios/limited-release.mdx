你发布一款测试产品，希望每个订单最多买 2 件。使用数量规则按产品分别计算，同一产品的不同颜色会合并计数。

## 适用场景

适合限量新品和零售促销。目标是限制同一产品每次购买的总件数。

## 开始前

准备一个前台可购买、库存足够的测试产品。变体 A和变体 B应是同一产品的两个变体。准备一个未选中的杯垫，用来确认范围。

## 配置参数

入口：应用首页 → **所有数量规则** → 创建规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | 测试产品每单最多 2 件 |
| 规则类型 | 购物车数量限制 |
| 最小购买数量 | 留空 |
| 最大购买数量 | 2 |
| 数量计算方式 | 分别限制每个适用商品 |
| 适用对象 | 指定产品，选择测试产品 |
| 显示时机 | 购物车互动时和结账时 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限购**。从应用首页进入 **所有数量规则**，点击 **创建规则**。
2. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
3. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
4. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **创建并启用**。编辑已有规则时点击 **保存并启用**。
5. 回到 **数量限制**，打开 **数量规则**。确认 **数量规则** 显示 **已开启**；如果显示为关闭，直接打开 **数量规则** 开关，直到状态显示 **已开启**。
6. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 产品 2 件 | 通过 |
| 产品 3 件 | 拦截 |
| 变体 A产品 1 件 + 变体 B产品 2 件，同属一个产品 | 拦截，产品合计 3 件 |
| 产品 2 件 + 未选中的杯垫 3 件 | 通过本条规则 |

<Note>本场景限制每次购物车的数量。顾客分多次下单时，不会自动共享这个 2 件上限。</Note>

需要管理再次购买？阅读[样品重复购买限制](/scenarios/repeat-purchase)。

## 结果不符时

不同颜色各买 2 件仍被限制是正常的：同一产品合计计算。不同产品要共用 2 件额度时，改用合计数量规则。
