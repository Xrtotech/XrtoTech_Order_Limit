你创建了一个会员专属产品系列，只希望带有 VIP 标签的客户购买。使用客户限制，同时要求客户登录。

## 适用场景

适合限制会员产品系列的购买资格。如果只是想给会员更高数量，应使用客户标签数量规则。

## 开始前

准备会员专属产品系列、一个有 VIP 标签和一个没有 VIP 标签的客户。确认顾客能在店铺前台登录各自账户。

## 配置参数

入口：应用首页 → **客户限制规则** → 创建客户限制规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | VIP 会员专属产品系列 |
| 客户标签 | VIP，输入后点击添加标签 |
| 标签限制方式 | 没有这些标签的客户不能购买 |
| 需要客户账户登录 | 勾选 |
| 适用对象 | 产品系列，选择会员专属产品系列 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 在 Shopify 后台打开 **应用** → **订单限制**。从应用首页进入 **客户限制规则**，点击 **创建规则**。
2. 先到 Shopify 客户资料添加表中的标签。回到规则输入相同标签，点击 **添加标签**，确认已显示为标签项，再选择表中的匹配方向。
3. 先按上表填写 **规则名称** 和限制数值。规则名称只用于后台管理，不会显示给顾客。
4. 在 **规则应用于** 选择表中的商品范围。选择 **指定产品** 或 **产品系列** 后，点击 **选择产品** 或 **选择产品系列**，选中对象并确认页面已列出名称。
5. 在 **标签限制方式** 核对表中的方向，并勾选 **需要客户账户登录**。
6. 按上表设置显示时机。在 **规则状态** 的 **保存后的状态** 选择 **已启用**，点击 **创建并启用**。编辑已有规则时点击 **保存并启用**。
7. 回到 **客户限制**，打开 **开启客户限制规则**。等待保存完成，确认页面没有错误信息。
8. 重新打开规则，核对数值、商品范围、客户条件和启用状态已保留，再按下表在店铺前台测试。

## 测试你的设置

每行结果只表示这条方案的判断。测试时使用同一商品范围，并进入结账确认；其他已启用规则仍可能拦截。

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且带 VIP 标签，购买专属商品 | 通过客户资格检查 |
| 已登录但没有 VIP 标签，购买专属商品 | 拦截 |
| 未登录，购买专属商品 | 要求登录 |
| 普通客户仅购买产品系列外商品 | 不受本条规则限制 |

<Warning>客户限制检查购买资格，不会自动隐藏产品页、价格或产品系列。商品仍可能被浏览。</Warning>

如果会员还需要独立额度，可叠加[VIP 数量限制](/scenarios/vip-quantity)。

## 结果不符时

VIP 反而被拦截时，先检查标签限制方向。必须选择“没有这些标签的客户不能购买”，并在规则和客户资料中都添加 VIP。

继续按[规则排查](/troubleshooting/rules-not-working)检查。正式启用前，完成[上线测试清单](/getting-started/launch-checklist)。
