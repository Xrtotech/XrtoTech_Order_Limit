你创建了一个会员专属系列，只希望带有 VIP 标签的客户购买。使用客户限制，同时要求客户登录。

## 配置参数

入口：应用首页 → **客户限制规则** → 创建客户限制规则。

| 设置项 | 示例值 |
| --- | --- |
| 规则名称 | VIP 会员专属系列 |
| 客户标签 | VIP，输入后点击添加标签 |
| 标签限制方式 | 没有这些标签的客户不能购买 |
| 需要客户账户登录 | 勾选 |
| 符合条件的物品 | 产品系列，选择会员专属系列 |
| 显示时机 | 仅结账时 |

## 操作步骤

1. 在 Shopify 客户资料中给有资格的客户添加 `VIP` 标签。
2. 按上表创建规则，务必选择 **没有这些标签的客户不能购买**。
3. 将状态设为 **已启用**，点击 **保存并启用**。回到 **客户限制**，打开 **开启客户限制规则**。

## 测试你的设置

| 测试条件 | 本场景预期结果 |
| --- | --- |
| 已登录且带 VIP 标签，购买专属商品 | 通过客户资格检查 |
| 已登录但没有 VIP 标签，购买专属商品 | 拦截 |
| 未登录，购买专属商品 | 要求登录 |
| 普通客户仅购买系列外商品 | 不受本条规则限制 |

<Warning>客户限制检查购买资格，不会自动隐藏产品页、价格或系列。商品仍可能被浏览。</Warning>

如果会员还需要独立额度，可叠加[VIP 数量限制](/scenarios/vip-quantity)。
