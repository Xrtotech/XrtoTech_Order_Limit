# Product brief

## Description
订单限购是 Shopify 商家使用的订单限制应用。当前源码支持数量、价格、重量、客户资格、客户标签和历史购买相关规则。

## Primary audience
Shopify 商家及店铺运营人员。用户确认中文为主要及默认语言，同时提供日文、英文。每种语言保持 23 页与 10 个场景，中文使用现有根路径，日文使用 `ja/`，英文使用 `en/`；站点品牌名称为“订单限制帮助中心”、英文“Order Limits Help Center”、日文“注文制限ヘルプセンター”。不展示厂商品牌名；应用中的实际中文界面名称仍按“订单限购”说明。

## Jobs to be done
- 先按经营场景选择规则，再按参数表配置。
- 启用第一条规则，区分单条状态、功能开关与实际校验。
- 用边界值和客户身份测试，排查叠加规则。

## Motivation
用户要求以不同经营场景的示例为重点，参考 RuffRuff 帮助中心的分类方式。品牌紫色取自用户提供的图片，固定浅色主题。

## Localization
- 中文是内容事实基准，修改功能时同时更新日文和英文。
- 翻译保留所有数值、标签示例、变量名、首购和历史统计边界。
- 应用源码当前 UI 为中文，英日文说明使用本地化描述并提供中文标签对照，不承诺应用自身多语言 UI。

## Evidence and assumptions
- 2026-10-26 核对相邻 xiangou 仓库的商家页面、校验函数与订单记录逻辑。
- 参考站仅用于信息结构，不作为本应用能力来源。
- 不编造套餐、费用、安装商店链接、支持邮箱或全渠道兼容承诺。
- 历史累计在源码与 UI 描述间有差异：以校验和订单记录实际行为为准，首次购买需另设单次规则；创建订单计数，未实现退款回退，不以规则启用时间为统计起点。
